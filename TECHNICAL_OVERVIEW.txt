PSNI Crime Map Project - Technical Overview
===========================================

Purpose
- Analyze PSNI crime data with geospatial joins, clustering, and trend analytics.
- Produce ward-level metrics, hotspot maps, and interactive visualizations.
- Provide Postgres/PostGIS loading and a FastAPI + React UI for exploration.

System Overview
- Ingestion: download PSNI street-level archives or query data.police.uk API.
- Processing: clean coordinates, spatially join crimes to wards, merge population.
- Analytics: compute crime rates, trend metrics, YoY change, harm scores.
- Clustering: DBSCAN on ward centroids or crime points with optional sweeps.
- Visualization: Folium maps for clusters, heatmaps, and ward choropleths.
- Serving: FastAPI reads CSV outputs; React UI renders summaries and maps.

End-to-End Data Flow (default pipeline)
1) Ingest -> data/raw/crime_data.csv and data/processed/crime_history.csv
2) Clean and join wards -> data/processed/cleaned_crime_data.csv
3) Merge wards + population -> data/processed/merged_data.csv
4) Cluster -> outputs/cluster_info.csv (+ outputs/dbscan_sweep.csv if sweep)
5) Analytics -> outputs/ward_crime_analysis.csv and outputs/ward_crime_type_trends.csv
6) Maps -> outputs/cluster_centers_map.html, outputs/crime_heatmap.html,
           outputs/wards_interactive_map.html
7) Optional Postgres load -> db/migrations via Alembic and src/postgres_writer.py

Outputs (key files and fields)
- outputs/cluster_info.csv
  - Cluster, Latitude, Longitude, CrimeCount, WardCount (WardCount only for ward-level clustering)
- outputs/dbscan_sweep.csv
  - eps_km, min_samples, total_points, noise_points, noise_share, cluster_count,
    avg_cluster_size, median_cluster_size, min_cluster_size, max_cluster_size
- outputs/ward_crime_analysis.csv
  - WardCode, WARDNAME, Population, NumberOfCrimes, CrimeRatePer100kPeople,
    RatePercentile, RateRank, HighCrimeRate, TotalCrimes, AvgMonthly,
    TrendChange, TrendPct, TrendSlope, YoYCurrent, YoYPrior, YoYChange,
    TotalHarm, HarmScorePer100k, Months, FirstMonth, LastMonth,
    AnnualizedCrimeRatePer100k, RatingScore, RatingBand
- outputs/ward_crime_type_trends.csv
  - WardCode, WARDNAME, Crime type, TotalCrimes, AvgMonthly, TrendChange,
    TrendPct, TrendSlope, Months, FirstMonth, LastMonth, TrendDirection
- outputs/police_api_gap_report.csv
  - CheckedAt, HistoryLatest, LatestAvailable, GapMonths, DefaultStartMonth
- outputs/wards_interactive_map.html
  - Ward polygons styled by rating band or rate percentile
- outputs/cluster_centers_map.html
  - Cluster centers with circle size scaled by CrimeCount
- outputs/crime_heatmap.html
  - Heatmap of crime points
- outputs/ward_hotspots_map.html and outputs/ward_hotspots_summary.csv
  - Generated by src/hotspot_map.py (not part of main pipeline)

Runtime Entrypoints
- src/main.py: main pipeline CLI, supports interactive prompt and flags.
- src/cli_menu.py: interactive menu for ingest, maps, and summaries.
- src/ingest_psni.py: PSNI archive downloader and history updater.
- src/ingest_police_api.py: API ingest using ward polygons or centroids.
- src/hotspot_map.py: ward-level hotspot map from history CSV.
- src/trend_report.py: ward and crime-type trend CSVs.
- backend/app/main.py: FastAPI service serving summaries and outputs.
- frontend: React + Vite UI using API endpoints.
- scripts/load_postgres.py: load CSV outputs into Postgres (Alembic schema).
- scripts/load_mysql.py: legacy loader for db/schema.sql.

File-by-File Reference (first-party code and config)

Root
- README.md: high-level project overview and usage examples for CLI, API, UI.
- TECHNICAL_OVERVIEW.txt: this document.
- conall_info: project notes and backlog ideas.
- geography-dz2021-esri-shapefile.zip: external shapefile data archive.

db/
- db/README.md: Postgres setup notes and legacy MySQL notes.
- db/migrations/: Alembic migrations for Postgres/PostGIS tables.
- db/schema.sql: legacy MySQL schema.

scripts/
- scripts/load_postgres.py
  - CLI wrapper around src/postgres_writer.load_from_csvs.
  - Reads env vars for Postgres connection defaults.
- scripts/load_mysql.py
  - Legacy MySQL loader wrapper.

src/
- src/main.py
  - build_parser/build_interface: CLI argument definition.
  - run_pipeline: orchestrates ingestion, cleaning, merge, clustering, analytics,
    map outputs, and optional Postgres load.
  - _add_rating_bands: computes RatingScore/RatingBand from rate percentiles and trend slope.
  - _safe_to_csv: CSV writer with fallback file name if locked.
  - Outputs: cleaned/merged CSVs, cluster_info, ward analyses, maps, dbscan_sweep.
- src/dataprocessing.py
  - clean_data: spatial join crimes to ward polygons and write cleaned CSV.
  - load_and_preprocess_data: merge ward geometry, crime counts, population,
    compute area and rate, emit merged CSV.
  - prepare_population_data: normalizes population CSV or Excel to Geo_Code, Geo_Name.
  - prepare_population_data_from_excel: handles ward sheet formats.
  - merge_population_by_name: fallback population matching by normalized name.
  - Outputs: data/processed/cleaned_crime_data.csv, data/processed/merged_data.csv,
    outputs/missing_population_report.csv (when population is missing).
- src/clustering.py
  - apply_dbscan: haversine DBSCAN on coordinates (km).
  - identify_high_density_areas: filter out noise clusters.
  - get_cluster_centers/count_crimes_per_cluster/merge_cluster_info: cluster summaries.
  - calculate_cluster_metrics: counts, noise share, min/avg/max sizes.
  - dbscan_sweep: grid search metrics across eps_km and min_samples.
  - Outputs: outputs/cluster_info.csv, outputs/dbscan_sweep.csv.
- src/visual.py
  - plot_clusters_on_map: cluster point map (not used in main pipeline).
  - plot_cluster_centers: circle markers sized by CrimeCount.
  - plot_crime_heatmap: heatmap of points.
  - plot_interactive_ward_map: ward polygons with tooltips and bands.
  - Outputs: outputs/cluster_centers_map.html, outputs/crime_heatmap.html,
    outputs/wards_interactive_map.html.
- src/analytics.py
  - filter_by_month_range: slice data by date range or months_back.
  - attach_wards: spatial join crimes to wards (optional geometry simplification).
  - ward_counts/ward_change_between_halves/crime_type_change_between_halves:
    count and delta summaries.
  - monthly_counts/_trend_metrics: build monthly series and slope/avg/change metrics.
  - build_ward_analysis: combines rate analysis, trends, YoY, harm scoring.
  - build_ward_crime_type_trends: trends per ward and crime type.
  - Outputs: outputs/ward_crime_analysis.csv, outputs/ward_crime_type_trends.csv,
    outputs/ward_trends.csv, outputs/crime_type_trends.csv (trend_report).
- src/ingest_psni.py
  - ingest_psni_month: downloads archive, writes data/raw/crime_data.csv and
    appends to data/processed/crime_history.csv.
  - update_psni_history: backfills missing months and de-duplicates.
  - check_history_gap: compares history latest vs latest available archive.
- src/ingest_police_api.py
  - update_police_api_history: pulls crimes from data.police.uk by ward
    polygons or centroids; writes raw and history CSVs.
  - check_police_api_gap: probes latest available API month.
  - _geometry_to_poly: simplifies polygon for API query limits.
  - Outputs: data/raw/crime_data.csv, data/processed/crime_history.csv,
    outputs/police_api_gap_report.csv (written by src/main.py).
- src/hotspot_map.py
  - build_hotspot_map: aggregates history by ward and builds choropleth map.
  - Outputs: outputs/ward_hotspots_map.html, outputs/ward_hotspots_summary.csv.
- src/trend_report.py
  - build_trend_report: ward and crime-type trend metrics for a time window.
  - Outputs: outputs/ward_trends.csv, outputs/crime_type_trends.csv.
- src/postgres_writer.py
  - connect_postgres: connect using DATABASE_URL or POSTGRES_* env vars.
  - upsert_wards/insert_*: batch insert CSV data with idempotent upserts.
  - load_from_csvs: main entry for CSV-to-Postgres sync + job_runs tracking.
- src/mysql_writer.py
  - Legacy MySQL CSV loader.
- src/utils.py
  - optimise_data_types: downcast numeric types and categorical objects.
  - calculate_crime_rate: per-100k rate with zero and NaN handling.
  - handle_missing_values: mean/median/mode/drop strategies.
  - haversine_distance/calculate_area_sq_km/extract_coordinates_from_geometry.
  - validate_required_columns/validate_coordinate_ranges/summarize_population_coverage.
- src/cli_menu.py
  - Interactive menu for ingest, hotspot map, trend summaries, and quick stats.

backend/
- backend/requirements.txt: FastAPI and Uvicorn dependencies.
- backend/app/__init__.py: package marker.
- backend/app/main.py
  - Loads outputs/ward_crime_analysis.csv and outputs/police_api_gap_report.csv.
  - Endpoints:
    - GET /api/health: status.
    - GET /api/summary: aggregated counts, rating bands, sparkline.
    - GET /api/wards: ward rows sorted by rating/rate/trend.
    - GET /api/gap-report: latest API gap info.
    - GET /api/map: map URL and file existence flag.
  - Serves outputs/ via /assets for map embedding.

frontend/
- frontend/package.json: React + Vite scripts and dependencies.
- frontend/package-lock.json: pinned dependency tree.
- frontend/vite.config.js: Vite config (dev server port 5173).
- frontend/index.html: root HTML and mount point.
- frontend/public/README.md: instructions for placing logo at public/logo.png.
- frontend/src/main.jsx: React entrypoint, renders App.
- frontend/src/App.jsx
  - Fetches /api/summary, /api/wards, /api/gap-report, /api/map.
  - Builds search, sorting, band filters, and ward detail panels.
  - Embeds the ward map in an iframe.
- frontend/src/styles.css
  - Themed dashboard styling, layouts, and responsive rules.
- frontend/src/CMI.png: bundled image asset (not referenced in code).

tests/
- tests/test_utils.py: unit tests for utils functions (rate, missing values,
  type optimization, haversine, geometry coordinates).

Data and Generated Assets
- data/raw: input datasets (crime_data.csv, population_data.csv,
  census-2021-ms-a01.xlsx, OSNI ward shapefile, etc).
- data/processed: pipeline outputs for cleaned and merged data plus history.
- data/old_files: archived data snapshots and experiments.
- outputs: generated CSVs and HTML maps used by the API and UI.
- geography-dz2021-esri-shapefile/: shapefile components for DZ2021.
- __pycache__ and frontend/node_modules: local build artifacts and dependencies.
